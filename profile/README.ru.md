# SilentCodeTeams

**Команда open-source инженерии SilentStudio**

> Второстепенный перевод. При расхождениях приоритет имеет версия на упрощённом китайском: [简体中文（основная）](README.md)

SilentCodeTeams — команда open-source инженерии SilentStudio, работающая над сетевыми протоколами, инструментами для разработчиков, кроссплатформенными системами и авторизованными исследованиями безопасности.

Команда не ограничивается одним проектом. NetTool ζ — один из текущих проектов; мы также занимаемся анализом протоколов, инженерными инструментами, системными экспериментами и инфраструктурой тестирования безопасности.

## Чем мы занимаемся

- Сетевые протоколы и анализ трафика
- Инструменты для разработчиков и автоматизация
- Кроссплатформенные системы и наблюдаемость
- Авторизованное тестирование безопасности и защитные исследования

## Проекты

| Проект | Описание | Статус |
| --- | --- | --- |
| NetTool ζ | Ядро на Rust для анализа сетевых протоколов и авторизованного тестирования безопасности | Публичный |
| Другие проекты | Эксперименты с протоколами, инструменты, системные компоненты | В работе |

## Принципы

- Open source в первую очередь, аудитируемость по умолчанию
- Rust в первую очередь; C только для системных шимов
- Разделение UI и бэкенда, изоляция сбоев
- Поддержка нескольких версий протоколов, метаданные в первую очередь
- Без самописной криптографии

## Участие

- Issues и pull requests приветствуются
- Следуйте CONTRIBUTING каждого репозитория
- Не перезаписывайте работу других; не делайте force-push в main

## Безопасность

- Используйте только на системах, которыми владеете или на тестирование которых есть разрешение
- Без скрытности, обхода или несанкционированного удалённого управления
- Сообщайте об уязвимостях приватно согласно SECURITY.md каждого репозитория
