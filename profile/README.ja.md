# SilentCodeTeams

**SilentStudio のオープンソースエンジニアリングチーム**

[简体中文](README.md) | [English](README.en.md) | 日本語 | [한국어](README.ko.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Русский](README.ru.md)

SilentCodeTeams は SilentStudio のオープンソースエンジニアリングチームです。ネットワークプロトコル、開発者ツール、クロスプラットフォームシステム、許可されたセキュリティ研究に取り組んでいます。

チームは複数のプロジェクトと領域にまたがって活動しており、ここでは個別には列挙しません。私たちはエンジニアリングの品質、保守性、多言語・マルチプラットフォームの実践、コミュニティとの協働を重視しています。

## 原則

- オープンソース優先、デフォルトで監査可能
- 多言語・マルチプラットフォーム、単一の技術スタックを前提としない
- 保守性、可観測性、ドキュメント
- UI とバックエンドの境界を明確にし、障害を分離
- 許可されたセキュリティ研究と明確な境界

## 参加

- issue と pull request を歓迎します
- 各リポジトリの CONTRIBUTING に従ってください
- 他者の作業を上書きしない；main へ force-push しない

## 保守とセキュリティ

- SilentCodeTeams はセキュリティ報告を重視し、透明に対応します。本ポリシーは SilentCodeTeams が保守するプロジェクトに適用されます。
- 最新の安定版は完全なセキュリティ更新を提供し、前の安定版は重大な修正のみ、それ以前は要望に応じて対応します。
- 脆弱性は SilentStudio@feedback.email.cn まで報告してください。修正前に詳細を公開しないでください。
- 受領確認は 24 時間以内、検証は 48 時間以内、重大な修正計画は 7 日以内、中・低リスクは 14 日以内。
- 善意の報告者を追及しません。データの悪用やシステムの妨害は行わないでください。
- 所有するシステム、または書面で許可されたテストにのみ使用してください。隠蔽、回避、未許可のリモート制御は提供しません。
- 最終更新：2026-11-03。
