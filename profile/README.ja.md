# SilentCodeTeams

**SilentStudio のオープンソースエンジニアリングチーム**

> 附属翻訳です。解釈に相違がある場合は簡体字中国語版を優先します: [简体中文（主）](README.md)

SilentCodeTeams は SilentStudio のオープンソースエンジニアリングチームです。ネットワークプロトコル、開発者ツール、クロスプラットフォームシステム、許可されたセキュリティ研究に取り組んでいます。

単一プロジェクトに限定されないチームです。NetTool ζ は現在の重点プロジェクトの一つで、ほかにプロトコル分析、エンジニアリングツール、システム実験、セキュリティテスト基盤にも取り組んでいます。

## 活動内容

- ネットワークプロトコルとトラフィック分析
- 開発者ツールと自動化
- クロスプラットフォームシステムと可観測性
- 許可されたセキュリティテストと防御研究

## プロジェクト

| プロジェクト | 説明 | 状態 |
| --- | --- | --- |
| NetTool ζ | Rust によるネットワークプロトコル分析と許可されたセキュリティテストの中核 | 公開 |
| その他 | プロトコル実験、開発者ツール、システムコンポーネント | 進行中 |

## 原則

- オープンソース優先、デフォルトで監査可能
- Rust 優先；C は OS の薄いシムのみ
- UI とバックエンドを分離し、クラッシュを隔離
- 複数バージョンのプロトコル、メタデータ優先
- 暗号を自作しない

## 参加

- issue と pull request を歓迎します
- 各リポジトリの CONTRIBUTING に従ってください
- 他者の作業を上書きしない；main へ force-push しない

## セキュリティ

- 所有するシステム、または書面で許可されたテストにのみ使用
- 隠蔽、回避、未許可のリモート制御は提供しない
- 脆弱性は各リポジトリの SECURITY.md に従い非公開で報告
