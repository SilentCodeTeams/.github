# SilentCodeTeams

**SilentStudio 산하 오픈소스 엔지니어링 팀**

> 부속 번역입니다. 해석에 차이가 있으면 중국어 간체 버전이 우선합니다: [简体中文（주）](README.md)

SilentCodeTeams는 SilentStudio 산하의 오픈소스 엔지니어링 팀으로, 네트워크 프로토콜, 개발자 도구, 크로스플랫폼 시스템, 허가된 보안 연구를 다룹니다.

단일 프로젝트에 한정되지 않습니다. NetTool ζ는 현재 중점 프로젝트 중 하나이며, 프로토콜 분석, 엔지니어링 도구, 시스템 실험, 보안 테스트 인프라도 함께 다룹니다.

## 하는 일

- 네트워크 프로토콜과 트래픽 분석
- 개발자 도구와 자동화
- 크로스플랫폼 시스템과 관측성
- 허가된 보안 테스트와 방어 연구

## 프로젝트

| 프로젝트 | 설명 | 상태 |
| --- | --- | --- |
| NetTool ζ | Rust 기반 네트워크 프로토콜 분석 및 허가된 보안 테스트 코어 | 공개 |
| 추가 프로젝트 | 프로토콜 실험, 개발자 도구, 시스템 구성 요소 | 진행 중 |

## 원칙

- 오픈소스 우선, 기본적으로 감사 가능
- Rust 우선; C는 OS 얇은 심(shim)에만 사용
- UI와 백엔드 분리, 크래시 격리
- 다중 버전 프로토콜, 메타데이터 우선
- 암호를 직접 구현하지 않음

## 참여

## 보안

- 소유한 시스템 또는 서면으로 허가된 테스트에만 사용
- 은닉, 회피, 무단 원격 제어 기능을 제공하지 않음
- 취약점은 각 저장소의 SECURITY.md에 따라 비공개로 보고
